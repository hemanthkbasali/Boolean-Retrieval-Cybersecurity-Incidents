Operators

AND
Both terms must appear. The result gets smaller.
OR
Either term may appear. The result gets bigger.
NOT
Leaves out incidents that contain the term.

Run a query and every step will be listed here with the number of incidents that remain.

How it works

  1. Documents. {{ doc_count }} incident reports are read from the database.
  2. Tokenize. tokenize() lowercases the text, keeps letters and drops stop words.
  3. Inverted index. build_index() maps each of {{ term_count }} terms to the ids of its documents.
  4. Parse the query. parse_query() splits it into terms and AND, OR, NOT.
  5. Set operations. search() uses intersection for AND, union for OR and complement for NOT.
